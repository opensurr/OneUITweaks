# OneUI Tweak

Shizuku-powered tweaks for Samsung One UI 8 and One UI 9. No root needed.

## Install
1. Go to the repository's Releases page and download OneUITweak.apk from the latest build.
2. Allow installing unknown apps for your browser or file manager when Android asks.
3. If an older OneUI Tweak build is already installed and install fails with a signature or conflict message, uninstall the old version first.
4. Install Shizuku from the Play Store or GitHub, then start it with Wireless debugging or ADB.
5. Open OneUI Tweak and grant Shizuku permission.
